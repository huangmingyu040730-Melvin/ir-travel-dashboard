## 更新

在 IR 工作台更新 Excel 底稿、重建快照、审核中文洞察并生成本地看板后，使用工作台的行业数据发布预演检查四文件差异；获得明确上线确认，再提交并推送至这里。GitHub Pages 自动构建，随后应核对站点的日期、指标和中英文展示。当前工作台本机发布仓已指向此仓库。

2026/9/27–10/3 的航空周度实测缺失。页面顶部参考周数值来自底稿左侧 QTD 8/30–9/5 行，仅作带日期的参考展示；周度航空图表仍保留缺值，后续有真正的当周数据时应优先显示实测。不要把参考周当成 9/27–10/3 同比写回指标快照。

旧的 `datamax.fun` 仍由原 EdgeOne 项目提供，不会随着本仓库更新。若要沿用原域名，需要域名/DNS 管理员将解析切换到新的托管项目，并另行验证，不能只改 GitHub 仓库。
